# 恒升内部 AI 经营助手演示

这是面向管理员、生产、仓库、工程和经营人员的内部助手，不是面向买家的售前客服。

## 入口与演示路径

- `index.html#assistant`：输入自然语言问题，查看答案及对应模拟记录。
- `index.html#systems`：查看 SAP ERP、MES、WMS、PLM 和设备采集的模拟适配器与字段。
- `index.html#wall`：生产大屏；播放模拟采样，或点击“大屏”进入展示模式。
- `index.html#reports`：报告计划、模拟时钟、飞书/企业应用卡片、投递记录、故障与重试。
- 其他视图保留订单、仓储、工程、采集、经营核算与改善情景。

建议依次提问：

1. “这张订单为什么会延期？”
2. “仓库缺口多少？隔离批次可以用吗？”
3. “图纸版本有什么问题？”
4. “利用率提高到 96% 能省多少？”
5. “每天早上 8:30 把生产日报发到飞书群。”

第五个问题会形成报告计划草稿。点击复核按钮，保存计划，再进入报告中心推进模拟时钟。查看生成时的报告、来源快照及接收端预览。可让下一次投递模拟失败，再重试同一份报告。每周与工作日计划、上海及 UTC 时区均可演示。

## 模拟与真实能力的区别

- 所有订单、库存、版本、设备、金额、报告与群名称均为虚构。
- 问答使用本地规则与确定性计算；没有真实 LLM、SAP、MES、WMS、PLM 或设备连接。不覆盖任意开放领域问题。
- 回答与报告保留本次查询的来源记录；历史报告不会随情景变化而改写。
- 计划和报告历史保存在浏览器中；只有手动推进报告时钟才运行到期任务。关闭网页后没有后台执行。
- 飞书群和企业应用只是消息卡片预览与投递状态模拟。没有 Webhook、Token、网络发送或真实群操作。
- 不对库存隔离、生产计划、采购或图纸进行写入。
- 工厂图片取自现有项目的企业影片画面，不是实时摄像头。
- 原有 `factory-demo/` 被复制复用，未修改、提交或部署其源目录。

## 正式建设的最小路径

先接入一条订单的只读查询：订单编号关联工单、批次、版本和设备时间窗口。保留来源时间、系统字段和访问范围；无法关联的数据显示缺失，不由模型猜测。

然后由服务端给真实语言模型提供受限查询和计算工具。报告调度也在服务端运行，负责时区、去重、权限、失败重试和审计。飞书或企业应用凭据保存在服务端，通过企业授权的接收渠道发送；不放进 GitHub Pages 或浏览器代码。

GitHub Pages 继续承载客户演示或前端；真实系统访问与持续定时任务需要另行接入服务端。本演示不代表上述服务已部署。

## 验证

在仓库根目录运行：

```sh
node --test demo/operations/tests/*.test.mjs
node --check demo/operations/app.js
node --check demo/operations/reports.mjs
```

覆盖模型计算、记录一致性、自然语言计划解析、时区、周计划、暂停与去重、故障模拟、报告快照及设备信号一致性。不是浏览器视觉测试。
