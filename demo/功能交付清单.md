# 恒升 B2B 客户演示｜功能交付清单

入口：[客户演示导览](portal.html#guide)。所有新增能力均在原 B2B 网站的副本中；原 `b2b/` 和 `b2c/` 文件未修改。

## 内部经营助手（最新聊天入口）

本次“聊天”明确指管理员使用的内部 AI 经营助手，而非买家客服。入口为 [AI 经营助手](operations/index.html#assistant)。

| 功能 | 可演示内容 |
|---|---|
| 自然语言问数 | 订单延期、物料缺口、隔离批次、版本异常、设备与改善计算 |
| 来源追溯 | 回答展示 SAP ERP、MES、WMS、PLM 或采集的模拟记录 |
| 系统与字段 | 查看模拟适配器、记录编号和结构化字段 |
| 生产大屏 | 当前订单风险、库存与七大制造中心的模拟信号 |
| 自然语言报告计划 | “每天 8:30 把生产日报发到飞书群”形成可复核的计划 |
| 定时与接收端 | 日、工作日、周计划；模拟飞书卡片与企业应用消息 |
| 历史与故障 | 保留报告快照，模拟投递失败与重试，下载报告 JSON |

报告时钟需手动推进，网页关闭后不执行任务。问答为本地规则演示，非已接入的真实语言模型。没有真实系统连接或外部消息发送。详细说明见 [运营演示说明](operations/README.md)。

## 预置虚构数据

后台首次打开会预置八位虚构客户，覆盖各个销售阶段，包含两份演示报价、三封跟进草稿、两条样品进度，以及明确标为虚构的分析数据。邮箱使用 example.com。聊天已预置买家与虚构顾问的对话，快速问题会得到规则生成的模拟回复，完整对话可保存为后台询盘。

初始化不会反复覆盖已有编辑。分析可切换“仅预置虚构数据”与“仅本地操作”。任何对话、业务或金额都不代表真实客户活动。

## 可以实际操作的功能

| 功能 | 如何演示 | 结果 |
|---|---|---|
| 制造与公司展示 | 打开复制的首页，查看工艺、工厂、质量与立柱拆解 | 保留原有品牌叙事、照片及交互结构展示 |
| 产品目录 | 搜索型号、名称或管型，按电动、共享、紧凑筛选 | 目录即时变化，有无结果状态 |
| 产品比较 | 选择最多三款产品，打开比较表 | 并列展示已知结构，未知参数标为待确认 |
| 产品详情 | 切换产品图与制造场景，选择颜色偏好和数量 | 配置进入询价篮 |
| 选型简报 | 在产品页点击下载 | 下载带有产品识别信息及需求清单的文本简报，不伪装成认证规格书 |
| 资料中心 | 选择尺寸图、测试、认证或包装资料 | 资料请求进入询价表；需求准备清单可下载 |
| 样品与 OEM 入口 | 在采购项目页选择样品产品或地区采购简报 | 样品标记或完整工程需求随询盘保存 |
| 美国采购页 | 在当地页面选产品、填写需求并切换计量单位 | 已填数值同步换算，原始单位与要求值被保留 |
| 德国采购页 | 用德语选产品，填写需求，选择资料与下一步 | 产品、技术背景、采购阶段一并进入销售记录；文本仍需母语审校 |
| 中英产品工具 | 切换目录、详情、资料中心等采购界面的语言 | 使用对应界面文字；不是宣称整站所有历史内容均已本地化 |
| 多产品询价 | 添加多款产品或样品，提交虚构联系信息 | 同一条完整记录出现在中文工作台 |
| 咨询入口 | 使用常见问题引导，或留下虚构邮箱与需求 | 咨询保存为独立询盘；没有在线真人或外部消息发送 |
| 客户工作台 | 搜索公司、联系人或负责人，按来源与阶段筛选 | 实际筛选本地记录 |
| 负责人和待办 | 指定负责人、下一步与日期，重新打开记录 | 保存安排，过期记录突出显示 |
| 销售阶段 | 打开阶段视图，调整某条记录的阶段 | 记录进入对应阶段，并留下操作历史 |
| 报价编辑 | 编辑行项目、数量、单价、币种、运费、有效期和条款 | 保存草稿并计算金额；未核价时不冒充完整总额 |
| 报价下载 | 在预览中下载 HTML 草稿 | 得到可单独打开、可用浏览器打印的草稿；不发送报价 |
| 跟进邮件 | 选择中、英、德模板，编辑主题与正文并保存 | 草稿可重新打开和下载；没有发送动作 |
| 样品进度 | 保存配置、费用、准备、寄出或评估等演示阶段及备注 | 本地样品工作视图同步显示进展，不产生实际物流动作 |
| 操作历史 | 查看客户记录底部 | 显示跟进、阶段、草稿与样品记录 |
| 数据导出 | 导出客户记录 | JSON 包含需求、报价、草稿、负责人及相关进展 |
| 本地操作分析 | 浏览产品、提交询价、保存报价后打开分析 | 展示实际演示操作次数与本地询盘来源；不会把次数称为独立访客或线上转化率 |
| 方案文件 | 打开客户价值说明和流量采购计划 | 简体中文解释自建路径、验收方式和按需外采原则 |

## 建议的现场演示顺序

1. 从导览进入产品目录，搜索并比较两款产品。
2. 打开一款产品，下载选型简报，申请样品并进入资料中心。
3. 将所需资料加入询价，使用虚构公司与邮箱提交。
4. 在工作台找到新记录，分配负责人和日期，保存下一步。
5. 编辑演示报价，先留空一个价格查看“待核价”，再填写演示金额并下载草稿。
6. 保存一封跟进邮件草稿；在样品页面保存一条进展记录。
7. 打开分析，看本次操作和询盘如何出现；导出客户记录。
8. 演示美国与德国采购页，让客户看到市场内容、单位与技术需求如何贯穿整个流程。

## 真实运行仍需接入的部分

本次交付为本地前端演示。真实消息、支付、物流、广告采购、身份认证、多用户数据库、系统提醒和正式数据分析均未启用。真实证书、CAD、测试报告不能通过生成演示界面代替。业务数据只存在当前浏览器中，清理浏览器可能丢失；正式使用需建设存储、权限、备份及恢复能力。

没有重新引入 B2C 购物和结账。平台专属排名、徽章及交易保障也没有被伪装为自有服务。
